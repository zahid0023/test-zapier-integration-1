# Set Environment Variables

To add environment variables:

1. Log into the **Platform UI**
2. Select your **integration**
3. In the Build section in the left sidebar, click **Advanced**
4. Add your environment variables by providing a key and value for each
5. Click **Add** to include additional environment variables, or click the **×** icon to remove variables if needed
6. Once you've completed adding keys and values, click **Save**
